# Listado de funcionalidades del proyecto

BarberRed - Agendamiento de horas para barberías

## Listado de funcionalidades

Por parte del usuario

- Revisar horas disponibles
- Seleccionar dia
- Seleccionar hora
- Seleccionar barbero
- Agendar hora
- Cancelar hora
- Ver mis horas agendadas

Del administrador o dueño de la barberia
- Panel para gestionar las horas, dias, etc.
- Poder habilitar/deshabilitar dias y horas
- Poder ver las horas agendadas
- Poder cancelar horas
